## 🎯 About This Project

This project is a scalable mobile storefront built to provide a seamless shopping experience. It features complete user authentication flows, product categorization, interactive item details, cart management, and user profile handling. The application is built with a strong focus on clean, responsive UI and efficient state management.

---

## ✨ Key Features

### Authentication
* Login / Sign Up UI workflows
* Password recovery screens

### E-Commerce Features
* Dynamic Home Screen with Featured Products
* Product Categories & Filtering
* Interactive Item Details & Image Galleries
* Shopping Cart Management
* User Profiles

---

## 👨‍💻 What I Built

* Flutter application architecture using MVC principles
* Pixel-perfect responsive UI implementation using VelocityX
* Reactive state management and routing using GetX
* Reusable custom UI components (Buttons, TextFields, App Logo)
* Separation of concerns with dedicated constants for strings, colors, and styles
